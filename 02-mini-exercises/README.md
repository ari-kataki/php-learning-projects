# 02 - mini exercises

Three small exercises, one folder each.

- `televideo/`: shows a page of RAI Televideo (100-800) as an image, with a TV drawn in CSS and page navigation. Needs internet, the images come from the Televideo website.
- `insurance-quote/`: insurance quote form (car or motorbike). The price is calculated in `Functions_php.php`, the form is checked in PHP and in JS. The file names say `Insurence`, it is a typo I kept.
- `calcolatrice/`: calculator with buttons, the operation is parsed and calculated in PHP.

Stack: PHP, JS, CSS. Run from MAMP, open `televideo.php`, `Insurence.php` or `calcolatrice.php`.

I was learning to split code into functions and files, and to validate user input.
