# 01 - phplearning

My first PHP exercises.

- `Telefono1.php` + `phone.php` + `StylePhone1.css`: phone dialer. The keypad fills an input, the green button calls, the page says if the number is valid (10 digits). Everything is done on the server side with a form.
- `Telefono2.php`: same dialer with some JavaScript for the buttons.
- `phpTest/`: other versions of the dialer (`Phone2.php`, `Telefono3.php`) and `Form.php` / `test.php`.
- `Form.php` / `test.php`: form tests with `$_POST`.
- `projectmark/`: `Blocchi_Importanti.php` is a cheat sheet of PHP syntax (if, for, functions, forms, include), `StudioFinale.php` and `casa_telefono.php` are study pages.
- `esempio.js` and `scripts.js`: first JavaScript drafts for the dialer. They are not linked from any page and `esempio.js` does not run, I kept them as they were.

Stack: PHP, HTML, CSS, a bit of JS. Run it from MAMP, open `Telefono1.php`.

Known issues: some files are drafts with mistakes in them on purpose of learning (typos in the JS, the `include` at the end of the cheat sheet points to files that don't exist). `Form.php` and `test.php` are duplicated in `phpTest/`.
